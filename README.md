# MyBank

Welcome to MyBank!

For this project, I have created a SmartContract emulating an online bank with conventional banking transaction:
1. Account Opening with minimum deposit
2. Deposit/ Withdraw/ Transfer function
3. Liquidity management system to manage liquidy across different banks and subsidiaries

Along with libraries and interfaces, I have created a bank without referring to crypto wallet addresses!

It has an account registry to manage client database. Useful for your reference if you need to deploy a CRM-like contract. Let me know your thoughts (:
